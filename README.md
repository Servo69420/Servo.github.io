# Adomas Šablovski – CV

Lietuviškas DI sistemų studento CV. Vieta: Lietuva.
Pritaikytas pateiktas FolioOne (template_1) šablonas; išsaugota BootstrapMade autorystė.

Atidarykite index.html naršyklėje arba VS Code pasirinkite „Open with Live Server“.
Svetainė veikia ir be diegimo ar interneto ryšio; visi reikalingi ištekliai yra vietiniai.
„Išsaugoti CV“ atidaro naršyklės spausdinimo langą. Pasirinkite „Išsaugoti kaip PDF“.

Pagrindiniai failai: index.html, assets/css/cv.css, assets/js/cv.js.
Pradinė iliustracija: assets/img/ai-network.svg (neuroninio tinklo iliustracija).
Favicon: assets/img/mark.svg.

Nepridėta nepatvirtintų darboviečių, laipsnių, kontaktų ar studijų datų.
Aprašomieji interesų tekstai yra redaguojamas CV juodraštis.
GitHub veiksmai neatlikti.
